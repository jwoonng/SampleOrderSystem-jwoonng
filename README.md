## 빌드 방법

- **IDE**: Visual Studio 2022
- **솔루션 파일**: `SampleOrderSystem.slnx`

| 구성 | 용도 |
|------|------|
| `Release \| x64` | 실제 콘솔 애플리케이션 실행 |
| `Debug \| x64` | 단위 테스트(Google Test) 실행 |

1. `SampleOrderSystem.slnx` 를 Visual Studio 2022로 열기
2. 상단 구성을 `Release | x64` 로 변경
3. **빌드 → 솔루션 빌드** (또는 `Ctrl+Shift+B`)
4. 빌드 결과물: `x64\Release\SampleOrderSystem.exe`

---

## 실행 방법

x64\Release\SampleOrderSystem.exe

## 메뉴별 사용 방법

---

### 1. 시료 관리

> **접근 역할**: 생산 담당자

시료(Sample)를 등록·조회·검색합니다. **시료가 먼저 등록되어야 주문이 가능합니다.**

#### 서브메뉴

```
[1] 시료 등록   [2] 시료 목록   [3] 시료 검색   [0] 위로
```

#### [1] 시료 등록

```
시료 ID (예: S-001)  > S-006
시료 이름            > 실리콘 웨이퍼-8인치
평균 생산시간(min)   > 0.5
수율 (0.0~1.0)       > 0.92
초기 재고            > 480
```

| 항목 | 형식 | 설명 |
|------|------|------|
| 시료 ID | `S-숫자` (예: S-001) | 대문자 S, 하이픈, 숫자 조합 |
| 평균 생산시간 | 양수 실수 | 시료 1개 생산에 걸리는 평균 시간 (단위: min/ea) |
| 수율 | 0.0 초과 ~ 1.0 이하 | 정상품 비율 (예: 0.92 = 92%) |
| 초기 재고 | 0 이상 정수 | 현재 보유 수량 (단위: ea) |

#### [2] 시료 목록

- 한 페이지에 **5건**씩 표시
- `N` 입력: 다음 페이지 / `P` 입력: 이전 페이지 / `0` 입력: 뒤로

```
등록 시료 목록  (총 12종)

ID          시료명               평균 생산시간    수율     현재 재고
S-001       실리콘 웨이퍼-8인치  0.5 min/ea      0.92     480 ea
S-002       GaN 에피택셀-4인치   0.3 min/ea      0.78     220 ea
...
```

#### [3] 시료 검색

- 시료 ID 또는 이름의 **일부 문자열**로 검색 가능
- 예: `웨이퍼` 입력 시 이름에 "웨이퍼"가 포함된 시료 모두 표시

### 2. 시료 주문

> **접근 역할**: 주문 담당자

고객의 시료 요청을 주문으로 등록합니다.

#### 입력 순서

```
시료 ID    > S-003
고객명     > 삼성전자 파운드리
주문 수량  > 200
```

#### 입력 내용 확인

입력 후 내용을 확인하고 `Y` 또는 `N` 을 선택합니다.

```
입력 내용 확인
시료    SiC 파워기판-6인치   (S-003)
고객    삼성전자 파운드리
수량    200 ea

[Y] 예약 접수   [N] 취소
선택 > Y
```

#### 등록 결과

```
예약 접수 완료.

주문번호    ORD-20260612-0043
현재 상태   [RESERVED]

※ 재고 확인은 [3] 승인 메뉴에서 직접 진행하세요.
```

> **중요**: 주문 등록 직후 상태는 `RESERVED`(예약 대기)입니다.  
> **생산라인에 등록되려면 반드시 [3] 주문 승인/거절 단계를 거쳐야 합니다.**

---

### 3. 주문 승인/거절

> **접근 역할**: 생산 담당자

`RESERVED` 상태의 주문 목록을 확인하고 **승인** 또는 **거절**을 처리합니다.

#### 대기 목록 표시

```
승인 대기 중인 예약 목록  (RESERVED)

번호    주문번호          고객               시료                   수량        상태
[1]     ORD-0041         LG이노텍           산화막 웨이퍼-SiO2     300 ea     [RESERVED]
[2]     ORD-0042         SK하이닉스         실리콘 웨이퍼-8인치    150 ea     [RESERVED]
[3]     ORD-0043         삼성전자 파운드리  SiC 파워기판-6인치     200 ea     [RESERVED]

승인할 번호 > 3
```

#### 재고 확인

승인할 번호를 선택하면 **자동으로 재고를 확인**하고 결과를 표시합니다.

**재고 부족인 경우**
```
재고 확인 중...

시료        SiC 파워기판-6인치    현재 재고  30 ea
주문 수량   200 ea                부족분     170 ea  ← 이 수량만 생산

재고 부족.  부족분 170 ea 승인하시겠습니까?  (실생산량 206 ea / 165 min)

[Y] 승인   [N] 주문 거절
선택 > Y

승인 완료.
상태 변경   RESERVED  →  [PRODUCING]
```

**재고 충분인 경우**
```
재고 확인 중...

시료        실리콘 웨이퍼-8인치   현재 재고  480 ea
주문 수량   150 ea

재고 충분.  바로 확정하시겠습니까?

[Y] 승인   [N] 주문 거절
선택 > Y

승인 완료.
상태 변경   RESERVED  →  [CONFIRMED]
```

#### 승인 결과 정리

| 조건 | 결과 |
|------|------|
| 재고 ≥ 주문 수량 | 재고 즉시 차감 → `CONFIRMED` (출고 대기) |
| 재고 < 주문 수량 | 생산라인 자동 등록 → `PRODUCING` (생산 중) |
| 거절 선택 | → `REJECTED` (이후 모니터링에서 제외) |

#### 생산량 계산 공식

```
부족분    = 주문 수량 - 현재 재고
실 생산량 = ceil(부족분 / (수율 × 0.9))
총 생산시간 = 평균 생산시간 × 실 생산량
```

> **예시**: 부족분 170ea, 수율 0.92  
> → 실 생산량 = ceil(170 / (0.92 × 0.9)) = ceil(170 / 0.828) = **206 ea**  
> → 총 생산시간 = 0.8 × 206 = **165 min**

### 4. 모니터링

> **접근 역할**: 공통 (주문 담당자 / 생산 담당자)

시스템 전반의 현황을 조회합니다. 조회 시각이 화면 상단에 표시됩니다.

#### 서브메뉴

```
[4] 모니터링   2026-06-12 09:32:15
──────────────────────────────────────────────────────────
[1] 주문량 확인   [2] 재고량 확인   [0] 위로
```

#### [1] 주문량 확인

```
상태별 주문 현황

[RESERVED]    3건
[CONFIRMED]   8건
[PRODUCING]   3건   ← 생산라인 대기
[RELEASE]     18건
```

> `REJECTED` 주문은 유효하지 않은 주문으로 간주하여 표시하지 않습니다.

#### [2] 재고량 확인

```
재고 현황

시료명                  재고        상태      잔여율
실리콘 웨이퍼-8인치     480 ea     [여유]    ████████░░  80%
GaN 에피택셀-4인치      220 ea     [여유]    █████░░░░░  44%
SiC 파워기판-6인치       30 ea     [부족]    █░░░░░░░░░   6%
산화막 웨이퍼-SiO2        0 ea     [고갈]    ░░░░░░░░░░   0%
```

| 상태 | 기준 | 색상 |
|------|------|------|
| 여유 | 주문 대비 재고 충분 | 초록색 |
| 부족 | 주문 대비 재고 부족 | 노란색 |
| 고갈 | 재고 = 0 | 빨간색 |

---

### 5. 생산라인 조회

> **접근 역할**: 생산 담당자

현재 생산 중인 작업과 대기 중인 작업 목록을 확인합니다.

```
[5] 생산라인 조회   FIFO 방식
──────────────────────────────────────────────────────────
생산라인  1개 (단일 라인)   현재 상태: [RUNNING]

현재 처리 중
┌──────────────────────────────────────────────────────┐
│ 주문번호  ORD-20260416-0038   시료  SiC 파워기판-6인치│
│ 주문량   80 ea   부족  50 ea  →  실생산량  61 ea      │
│ 진행     ████████░░  72%   완료 예정  09:49           │
└──────────────────────────────────────────────────────┘

대기 중인 주문  (FIFO 순)

순서    주문번호       시료                   주문량    부족분    실생산량   예상 완료
1       ORD-0040      산화막 웨이퍼-SiO2     150 ea    150 ea    190 ea     11:43
2       ORD-0043      SiC 파워기판-6인치     200 ea    170 ea    206 ea     14:28
```

- 생산은 **선입선출(FIFO)** 방식으로 처리됩니다.
- 진행률은 **조회 시각 기준**으로 계산됩니다.
- 생산 완료 시 자동으로 재고에 반영되고 주문 상태가 `CONFIRMED`로 변경됩니다.

---

### 6. 출고 처리

> **접근 역할**: 생산 담당자

`CONFIRMED`(출고 대기) 상태의 주문을 출고 처리합니다.

```
출고 가능 주문  (CONFIRMED)

번호    주문번호          고객           시료                   수량
[1]     ORD-0042         SK하이닉스     실리콘 웨이퍼-8인치    150 ea
[2]     ORD-0035         DB하이텍       포토레지스트-PR7       400 ea

출고할 번호 > 1

출고 처리 완료.
주문번호    ORD-20260416-0042
출고수량    150 ea
처리일시    2026-06-12 09:34:02
상태        CONFIRMED  →  [RELEASE]
```

## 주문 상태 설명

| 상태 | 설명 | 다음 단계 |
|------|------|-----------|
| `RESERVED` | 주문 접수 완료, 승인 대기 중 | [3] 주문 승인/거절 |
| `REJECTED` | 주문 거절됨 (최종 상태) | — |
| `PRODUCING` | 재고 부족으로 생산 진행 중 | 생산 완료 시 자동 전환 |
| `CONFIRMED` | 출고 대기 중 | [6] 출고 처리 |
| `RELEASE` | 출고 완료 (최종 상태) | — |

## 데이터 저장

모든 데이터는 `data/` 폴더에 JSON 파일로 저장됩니다.  
프로그램을 재시작해도 데이터가 유지됩니다.

| 파일 | 저장 내용 |
|------|-----------|
| `data/samples.json` | 등록된 시료 목록 |
| `data/orders.json` | 전체 주문 목록 |
| `data/production.json` | 생산 큐 (대기 중인 작업) |

> **초기화**: `data/` 폴더를 삭제하면 모든 데이터가 초기화됩니다.
