# 3-6. 생산라인

## 요구사항

재고 부족 시 자동 등록된 생산 작업을 관리.

## 생산량 계산

```
부족분      = 주문 수량 - 현재 재고
실 생산량   = ceil(부족분 / (수율 × 0.9))
총 생산시간 = 평균 생산시간 × 실 생산량
```

## 생산 완료 처리

- 실 생산량 전량을 양품으로 간주하여 재고에 그대로 반영
- 예: 부족분 100개 → 실 생산량 120개 → 재고 +120
- 재고 반영 후 주문 수량 차감, 주문 상태 `PRODUCING` → `CONFIRMED` 자동 전환

## 실시간 생산 처리

생산 진행은 실제 경과 시간 기반으로 계산된다. → [prd_008.md](prd_008.md) 참조

## 기능 목록

| 기능 | 설명 |
|------|------|
| 생산 현황 표기 | 현재 생산 중인 시료 정보 (주문 정보, 진행률 등) |
| 대기 주문 확인 | 생산 큐 목록 출력, 스케줄링 전략: **FIFO** |

## 진행률 계산

- `진행률(%) = (getElapsedQty / actualQty) × 100`
- 진행바: 10칸 기준
- 완료 예정 시각: `startTime + totalTime` (분 단위 → HH:MM 형식)
