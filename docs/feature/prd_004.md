# 3-4. 주문 승인/거절

## 요구사항

`RESERVED` 상태의 주문 목록을 확인하고 승인 또는 거절 처리.

## 처리 흐름

| 처리 | 조건 | 동작 |
|------|------|------|
| 승인 — 재고 충분 | 현재 재고 ≥ 주문 수량 | 재고 차감, 주문 `CONFIRMED` 전환 |
| 승인 — 재고 부족 | 현재 재고 < 주문 수량 | 생산 라인 자동 등록, 주문 `PRODUCING` 전환 |
| 거절 | — | 주문 즉시 `REJECTED` 전환 |

## 재고 부족 시 생산 등록 정보

- 부족분 = 주문 수량 - 현재 재고
- 실 생산량 = `ceil(부족분 / (수율 × 0.9))`
- 총 생산 시간 = `평균 생산시간 × 실 생산량`

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `[3] 주문 승인/거절` 제목 | Cyan |
| 테이블 헤더 | Cyan |
| `[RESERVED]` 배지 | Magenta |
| 현재 재고 수치 (재고 충분) | Green |
| 현재 재고 수치 (재고 부족) | Yellow |
| 부족분 수치 | Red |
| 경고 메시지 (`재고 부족.`) | Yellow |
| `승인 완료.` 메시지 | Green |
| `[CONFIRMED]` 배지 | Green |
| `[PRODUCING]` 배지 | Yellow |
| 오류 메시지 | Red |
| `선택 >` 프롬프트 | Yellow |
