# 3-8. 실시간 생산 처리

## 요구사항

Release 모드에서 생산 진행은 실제 경과 시간을 기준으로 계산된다.

## 동작 방식

- 생산 작업 등록 시 시작 시각(`startTime`)을 기록한다.
- 재고 조회 시점에 `(현재 시각 - startTime)`으로 경과 시간을 계산한다.
- 경과 시간 동안 생산된 수량을 아래 공식으로 계산하여 재고에 반영한다.

```
경과 생산량 = floor(경과 시간 / 평균 생산시간)
```

- 경과 생산량이 실 생산량에 도달하면 생산 완료로 처리한다.
  - 실 생산량 전량을 재고에 반영
  - 주문 상태 `PRODUCING` → `CONFIRMED` 전환

## 조회 동작

- 재고 및 생산 현황 조회는 **조회한 시각 기준의 스냅샷**으로 표시한다.
- 조회 화면이 열려 있는 동안 수치가 자동 갱신될 필요는 없다.
- 모든 조회 화면에는 **조회 시각**을 함께 표시한다.

## 적용 범위

| 화면 | 적용 내용 |
|------|-----------|
| 모니터링 — 재고량 확인 | 조회 시각 기준 재고 수량 표시 |
| 생산라인 조회 | 조회 시각 기준 진행률 및 생산량 표시 |
| 메인 메뉴 요약 | 조회 시각 기준 총 재고 표시 |
