# 3-5. 모니터링

## 요구사항

담당자가 시스템 현황을 한눈에 파악.

## 주문량 확인

- 상태별 주문 수 표시: `RESERVED` / `CONFIRMED` / `PRODUCING` / `RELEASE`
- `REJECTED`는 유효한 주문이 아니므로 제외

## 조회 시각 표시

- 모든 모니터링 화면은 **조회한 시각**을 함께 표시한다.
- 조회는 조회 시각 기준 스냅샷으로 표시하며, 화면이 열린 동안 자동 갱신하지 않는다.
- 실시간 생산 수량 반영 → [prd_008.md](prd_008.md) 참조

## 재고량 확인

시료별 현재 재고 수량 및 재고 상태 표기.

| 상태 | 기준 |
|------|------|
| 여유 | 주문 대비 재고 충분 |
| 부족 | 주문 대비 재고 수량 부족 |
| 고갈 | 재고 수량 0 |

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `[4] 모니터링` 제목 + 조회 시각 | Cyan |
| 서브메뉴 번호 | Cyan |
| `[RESERVED]` 배지 | Magenta |
| `[CONFIRMED]` 배지 | Green |
| `[PRODUCING]` 배지 | Yellow |
| `[RELEASE]` 배지 | Magenta |
| `[여유]` 배지 | Green |
| `[부족]` 배지 | Yellow |
| `[고갈]` 배지 | Red |
| 진행바 채워진 부분 (`█`) | Green (여유) / Yellow (부족) / Red (고갈) |
| 진행바 빈 부분 (`░`) | Dark Gray |
| `선택 >` 프롬프트 | Yellow |

## 잔여율 계산

- 기준 재고량: 해당 시료의 최대 재고 또는 최초 등록 재고 (→ `stock / (stock + 총주문량)`)
- 진행바: 10칸 기준 (`█` 채움 + `░` 빈칸), 백분율 표시
- 예: 80% → `████████░░  80%`
