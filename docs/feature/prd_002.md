# 3-2. 시료 관리

## 요구사항

시료(Sample)는 시스템의 기본 단위. 등록된 시료만 주문 가능.

## 단위 정의

| 단위 | 설명 |
|------|------|
| `ea` | 시료 수량 단위 (개) |
| `min` | 생산 시간 단위 (분) |
| `min/ea` | 개별 평균 생산시간 단위 (시료 1개 생산에 소요되는 분) |

## 시료 속성

| 속성 | 타입 | 단위 | 설명 |
|------|------|------|------|
| 시료 ID | string | — | 고유 식별자 (예: S-001) |
| 이름 | string | — | 시료명 |
| 평균 생산시간 | double | min/ea | 시료 1개 생산에 소요되는 평균 시간 |
| 수율 | double | — | 정상 시료 / 총 생산 시료 (0.0 초과 ~ 1.0 이하) |
| 재고 | int | ea | 현재 보유 수량 |

## 기능 목록

| 기능 | 설명 |
|------|------|
| 시료 등록 | 새로운 시료를 시스템에 추가 |
| 시료 조회 | 등록된 전체 시료 목록 및 현재 재고 수량 확인 |
| 시료 검색 | 이름 등 속성으로 특정 시료 검색 |

## UI 레이아웃

### 진입 화면

```
══════════════════════════════════════════════════════════
[1] 시료 관리
──────────────────────────────────────────────────────────
[1] 시료 등록   [2] 시료 목록   [3] 시료 검색   [0] 위로
선택 > _
```

### 시료 목록 (선택 > 2)

```
──────────────────────────────────────────────────────────
등록 시료 목록  (총 N종)

ID          시료명              평균 생산시간    수율     현재 재고
S-001       실리콘 웨이퍼-8인치  0.5 min/ea      0.92     480 ea
S-002       GaN 에피택셀-4인치   0.3 min/ea      0.78     220 ea
...외 N종   [N] 다음페이지
선택 > _
```

### 시료 등록 (선택 > 1)

```
──────────────────────────────────────────────────────────
시료 ID       > S-006

──────────────────────────────────────────────────────────
등록 완료.
시료 ID  S-006  이(가) 등록되었습니다.
선택 > _
```

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `[1] 시료 관리` 제목 | Cyan |
| 서브메뉴 번호 | Cyan |
| 테이블 헤더 (ID, 시료명 …) | Cyan |
| 테이블 데이터 | White |
| 성공 메시지 | Green |
| 오류 메시지 | Red |
| `선택 >` 프롬프트 | Yellow |

## 페이지네이션

- 한 페이지에 5건 표시
- `...외 N종  [N] 다음페이지` 표시
- `[P] 이전페이지` (2페이지 이상일 때)
