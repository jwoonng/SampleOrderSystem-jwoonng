# 3-1. 메인 메뉴

## 요구사항

- 기능별 선택 화면 표시
- 전체 시료 요약 정보 표시 (등록 시료 수, 총 재고, 전체 주문 수, 생산라인 대기 수)

## 메뉴 구성

| 메뉴 번호 | 메뉴명 | 접근 역할 |
|-----------|--------|-----------|
| 1 | 시료 관리 | 생산 담당자 |
| 2 | 시료 주문 | 주문 담당자 |
| 3 | 주문 승인/거절 | 생산 담당자 |
| 4 | 모니터링 | 공통 |
| 5 | 생산라인 조회 | 생산 담당자 |
| 6 | 출고 처리 | 생산 담당자 |
| 0 | 종료 | 공통 |

## UI 레이아웃

```
시스템 현황   YYYY-MM-DD HH:MM:SS
──────────────────────────────────────────────────────────
등록 시료  N종     총 재고    N,NNN ea
전체 주문  N건     생산라인   N건 대기
──────────────────────────────────────────────────────────
[1] 시료 관리                          [2] 시료 주문
[3] 주문 승인/거절                     [4] 모니터링
[5] 생산라인 조회                      [6] 출고 처리
[0] 종료
──────────────────────────────────────────────────────────
선택 > _
```

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `시스템 현황` 헤더 | Cyan |
| 메뉴 번호 (`[1]`, `[2]` …) | Cyan |
| 총 재고 수치 | Yellow |
| 생산라인 대기 수치 | Yellow |
| `선택 >` 프롬프트 | Yellow |

## 요약 정보 계산

| 항목 | 계산 방법 |
|------|-----------|
| 등록 시료 | `SampleService.getAllSamples().size()` |
| 총 재고 | 전체 시료의 `stock` 합산 |
| 전체 주문 | `OrderService`의 전체 주문 수 (REJECTED 포함) |
| 생산라인 대기 | `ProductionService.getQueue().size()` |
