# 3-1. 메인 메뉴

## 요구사항

- 기능별 선택 화면 표시
- 전체 시료 요약 정보 표시 (등록 시료 수, 총 재고, 전체 주문 수, 생산라인 대기 수)

## 메뉴 구성

| 메뉴 번호 | 메뉴명 | 접근 역할 |
|-----------|--------|-----------|
| 1 | 시료 관리 | 생산 담당자 |
| 2 | 시료 주문 | 주문 담당자 |
| 3 | 주문 승인/거절 | 생산 담당자 |
| 4 | 모니터링 | 공통 |
| 5 | 생산라인 조회 | 생산 담당자 |
| 6 | 출고 처리 | 생산 담당자 |
| 0 | 종료 | 공통 |
