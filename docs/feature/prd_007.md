# 3-7. 출고 처리

## 요구사항

`CONFIRMED` 상태 주문에 대해 출고 실행.

## 처리 흐름

1. `CONFIRMED` 상태의 주문 목록 표시
2. 출고할 주문 선택 (번호 입력)
3. 출고 처리 실행 → 주문 상태 `CONFIRMED` → `RELEASE` 전환

## UI 레이아웃

```
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
출고 가능 주문  (CONFIRMED)

번호    주문번호          고객           시료                   수량
[1]     ORD-0042         SK하이닉스     실리콘 웨이퍼-8인치    150 ea
[2]     ORD-0035         DB하이텍       포토레지스트-PR7       400 ea

출고할 번호 > 1
──────────────────────────────────────────────────────────
출고 처리 완료.

주문번호    ORD-20260416-0042
출고수량    150 ea
처리일시    2026-06-12 09:34:02
상태        CONFIRMED  →  [RELEASE]

선택 > _
```

### 출고 가능 주문이 없는 경우

```
출고 가능 주문  (CONFIRMED)

출고 대기 중인 주문이 없습니다.

선택 > _
```

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `[6] 출고 처리` 제목 | Cyan |
| 테이블 헤더 | Cyan |
| 번호 (`[1]`, `[2]`) | Cyan |
| `출고 처리 완료.` 메시지 | Green |
| `[RELEASE]` 배지 | Magenta |
| 처리일시 수치 | White |
| 오류 메시지 | Red |
| `출고할 번호 >` 프롬프트 | Yellow |
| `선택 >` 프롬프트 | Yellow |

## 처리일시

- 출고 처리 시점의 시스템 시각을 기록한다.
- 형식: `YYYY-MM-DD HH:MM:SS`
- `std::chrono::system_clock::now()` 기반
