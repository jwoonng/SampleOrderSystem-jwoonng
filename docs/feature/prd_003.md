# 3-3. 시료 주문 (접수)

## 요구사항

고객의 시료 요청을 주문 담당자가 시스템에 등록.

## 입력 값

| 항목 | 설명 |
|------|------|
| 시료 ID | 등록된 시료의 ID |
| 고객명 | 주문 고객명 |
| 주문 수량 | 요청 수량 (1 이상) |

## 처리 결과

- 주문 생성, 상태 `RESERVED`
- 주문번호 자동 발번: `ORD-YYYYMMDD-XXXX` (4자리 시퀀스, 당일 누적 순번)

## UI 레이아웃

```
══════════════════════════════════════════════════════════
[2] 시료 주문
──────────────────────────────────────────────────────────
시료 ID    > S-003
고객명     > 삼성전자 파운드리
주문 수량  > 200
──────────────────────────────────────────────────────────
입력 내용 확인
시료    SiC 파워기판-6인치   (S-003)
고객    삼성전자 파운드리
수량    200 ea

[Y] 예약 접수   [N] 취소
선택 > Y
──────────────────────────────────────────────────────────
예약 접수 완료.

주문번호    ORD-20260612-0001
현재 상태   [RESERVED]

※ 재고 확인은 [3] 승인 메뉴에서 직접 진행하세요.

선택 > _
```

## 색상 규칙

| 요소 | 색상 |
|------|------|
| `[2] 시료 주문` 제목 | Cyan |
| 입력 프롬프트 (`시료 ID >` 등) | Yellow |
| `입력 내용 확인` 헤더 | White |
| `[Y]`, `[N]` 선택지 | Cyan |
| `예약 접수 완료.` 메시지 | Green |
| `[RESERVED]` 배지 | 보라색 (DARK_MAGENTA 또는 MAGENTA) |
| 오류 메시지 (없는 시료 ID 등) | Red |
| `선택 >` 프롬프트 | Yellow |

## 주문번호 발번 규칙

- 형식: `ORD-YYYYMMDD-XXXX`
- XXXX: 전체 주문 수 기준 4자리 순번 (예: 0001, 0042)
- 당일 날짜 기준, 시스템 시각(`std::chrono`) 사용
